# Screenshot Plan

Current Apple guidance checked on March 30, 2026:

- App Store Connect requires one to ten screenshots per required platform set.
- For iPhone apps, providing a 6.9-inch set satisfies the current required iPhone submission slot.
- For iPad apps, a 13-inch set is required when the app runs on iPad.
- App previews are optional, but Apple notes they are not available for iMessage.
- iMessage screenshots are uploaded in the separate iMessage App section.

Minimum required sets for this app:

1. iPhone screenshots
Use one 6.9-inch portrait set.
Accepted sizes currently include `1320 x 2868`, `1290 x 2796`, or `1260 x 2736`.

2. iPad screenshots
Use one 13-inch portrait set.
Accepted sizes currently include `2064 x 2752` or `2048 x 2732`.

3. iMessage screenshots
Upload in the iMessage App section for the same app version in App Store Connect.

Recommended iPhone shot list:

1. Onboarding or home screen showing the core value proposition.
2. Create Poll flow with date range and availability grid.
3. Poll detail voting screen with Yes, Maybe, and No actions.
4. Real-time results or best-time ranking.
5. Finalized event with Add to Calendar and reactions.

Recommended iPad shot list:

1. Home screen on iPad.
2. Create Poll flow using the wider layout.
3. Poll detail screen with results visible.

Recommended iMessage shot list:

1. Compose a poll inside Messages.
2. Received poll card inside a conversation.
3. Voting or finalized flow inside the Messages extension.

Practical capture notes:

- Keep screenshots in portrait unless there is a strong reason to switch.
- Use real app UI captured from the app, not marketing mockups.
- Make the first one to three screenshots communicate the app value immediately.
- Include at least one dark-mode shot because the product is visually dark-first.
- Use the production backend and realistic sample poll data before capture.
